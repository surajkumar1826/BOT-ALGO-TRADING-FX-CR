# BOT-ALGO-TRADING-FX-CR
bot algo trading fx-Cr is a paper-trading terminal for Forex, Metals, Oil, US Indices and Crypto (24/7). It scans 16 instruments and ranks them by a confluence score built from Smart Money Concepts (BOS/OB/FVG), Fib OTE zones, multi-timeframe trend alignment, session killzones, volume profile/VWAP and macro regime.
